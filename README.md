1) check the version
2) create the venv folder
    python -m venv venv
3) Activate venv
    venv\Scripts\activate
4) install required Lib
    pip install notebook jupyter pandas numpy matplotlib seaborn plotly scikit-learn
5) Launch Jupyter
    jupyter notebook // browser launches jupyter
6) save the file after coding, shut down the kernel, ctrl+C in VScode and launch jupyter whenever you want
